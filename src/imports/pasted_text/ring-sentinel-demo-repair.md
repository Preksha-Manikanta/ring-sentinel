# 2. UNDERSTAND THE LOCALHOST PROBLEM

Remember:

```text
Browser
localhost:8000
```

means:

> port 8000 on the machine/environment where the browser is executing.

It does NOT automatically mean:

> the Python server running elsewhere.

Therefore, if the frontend is hosted remotely, this is invalid:

```text
Hosted frontend
      ↓
ws://localhost:8000/events
      ↓
browser's localhost
      ↓
NO FASTAPI
```

```text
Browser
   ↓
https://frontend-host
   │
   │ WSS
   ▼
https://backend-host
   │
   ▼
FastAPI
```
